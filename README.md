# Clinical Trial Data Quality & Safety Monitoring Dashboard

## Overview
A self-directed Excel portfolio project demonstrating clinical-trial data quality review, query management, and descriptive safety monitoring using a fully synthetic clinical-trial dataset.

## Objectives
- Identify potential data-quality issues across participant, visit, and adverse-event records.
- Apply rule-based validation using Excel formulas.
- Track data queries, priorities, statuses, resolutions, and query ageing.
- Summarize operational and safety data using a dashboard.

## Key Features
- **Data validation:** Duplicate IDs, missing fields, out-of-range values, date inconsistencies, and participant-linkage checks.
- **Query management:** Issue descriptions, suggested follow-up actions, priority levels, status tracking, and resolution notes.
- **Safety summaries:** Adverse events by reported severity and seriousness, with descriptive treatment-arm comparisons.
- **Dashboard reporting:** Participant and visit metrics, site-level data-quality summaries, and query-status indicators.
- **Configurable rules:** Editable validation limits that feed into formula-based checks.

## Tools Used
Microsoft Excel, formulas (IF, COUNTIF, COUNTIFS, INDEX/MATCH, SUMPRODUCT), data validation logic, dashboard reporting.

## Important Limitations
This is an educational portfolio project, not a validated clinical system. All data are synthetic; no real patient information is included. Flags indicate records requiring review and do not establish confirmed errors, medical significance, causality, or regulatory reportability.
